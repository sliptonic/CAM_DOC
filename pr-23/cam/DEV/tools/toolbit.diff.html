CAM ToolBit

Description

Toolbits are the foundation of the CAM Tools system. They represent a specific tool that can be used in a CAM Job to generate a Toolpath. Each Tool Bit is stored as a JSON file. JSON is structured data that can be easily parsed by macros or python scripts but remains human readable. Describing Tool Bits with JSON allows for the possibility of automatically creating large collections of accurate Tool Bits with a script.

Storing a tool as a JSON file sounds great but eliminates the option of an accurate thumbnail or solid body representation. On the other hand, if each Tool Bit were created as a FreeCAD object, obtaining the solid body would be simple but would require enormous storage for large tool collections. Also automatically creating Tool Bits as FreeCAD objects would be difficult or impossible.

Instead, the Tool Bit is a hybrid. The JSON file names the Tool Shape by its ID (for example endmill.fcstd, looked up in the Tools/Shape folder of the asset directory or the shipped shapes) and stores the values of the shape parameters and attributes.

When a Tool Bit is added to a Job, the Tool Shape body is copied into the document (hidden, property BitBody) and its solid is assigned to the Tool Bit object. Changing a parameter in the Shape group of the Tool Bit updates the solid after the next recompute. This provides the correct shape and dimensions which can be used to generate a point cloud or mesh for advanced algorithms (and potentially simulation).

Usage

Within the FreeCAD GUI the Library Manager provides a mechanism to create a new Tool Bit. A single Tool Bit can exist in multiple Tool Libraries.

  1. Select CAM  Toolbit Library Manager.

  2. Select a library (or All Toolbits).

  3. Press the Adds a toolbit button and pick a Tool Shape in the Toolbit Shape Selection dialog.

  4. In the Toolbit Parameter Editor set the Label, Tool Number (only when a library is selected; the next free number is proposed), the Toolbit Type (editable only for shapes with subtypes, for example Drill: jobber, stub, spot, center, brad point), the shape parameters and the attributes, then press OK.

  5. To edit an existing Tool Bit, double-click it in the Library Manager or in the Toolbit Selector, or select it and press F2.

Toolbit Parameter Editor

The editor (window title Toolbit Parameter Editor) has two tabs:

  • Toolbit: Label, Toolbit Type, optional Tool Number, a Properties list (Shape and Attributes groups) with the abbreviations used in the shape drawing shown next to each parameter, and the shape drawing.

  • Feeds && Speeds introduced in 26.3: a table of the presets stored on the Tool Bit with Add preset, Edit, Copy and Delete buttons; see CAM FeedsSpeeds.

The figure shows the Toolbit tab for the shipped Tool Bit 5mm Endmill.

The Properties list has no field for a calculated parameter, for example the Diameter of the Chamfer shape; see Tool Shape.

A Notes tab exists in the dialog definition but is hidden.

While the Toolbit Parameter Editor is open, the FreeCAD unit schema is temporarily switched to the Tool Bit’s Units setting so that parameters are entered in the tool’s native units; the previous schema is restored when the editor closes.

The length fields of the Toolbit Parameter Editor show the Tool Bit precision: 4 decimals when the unit schema is Imperial and 3 decimals for all other unit schemas. The Units Decimals preference does not change the number of decimals in the length fields.

Properties

Base

  • ShapeID (String, read-only): ID of the Tool Shape (.fcstd).

  • ShapeType (Enumeration, read-only): the shape class (Endmill, Ballend, Bullnose, Chamfer, Drill, VBit, Dovetail, Reamer, SlittingSaw, Tap, ThreadMill, Probe, TaperedBallNose, Radius, Custom).

  • ToolBitID (String, read-only): the unique ID of the Tool Bit (its file name in the library).

  • BitBody (Link, hidden): the parametrized body.

Shape

One property per parameter of the Tool Shape, for example Diameter, Length, CuttingEdgeHeight, ShankDiameter, Flutes. See CAM ToolShape for the list per shape.

Attributes

  • Units (Enumeration: Metric, Imperial) Metric, Imperial) introduced in 26.3: measurement units of the Tool Bit. The Toolbit Parameter Editor shows the values in these units and FreeCAD saves the values in these units. Default: Metric.

    unit system used to display the Tool Bit’s parameters.

  • SpindleDirection (Enumeration: Forward, Reverse, None): default spindle direction; copied to the Tool Controller when the Tool Bit is added to a Job. Probes never rotate.

  • Material (Enumeration: HSS, Carbide): tool material; used by the Feeds and Speeds helper to pick the matching surface speed of the Stock material.

  • Chipload (Length, cutting tools only): default chipload per tooth, used as a low-confidence fallback by the Feeds and Speeds helper.

Feeds & Speeds

  • Presets (String, only present once a preset was saved) introduced in 26.3: JSON list of Feeds & Speeds presets.

JSON Structure

introduced in 26.3: a Tool Bit can have a Units parameter with the value ToolBit can define a Units parameter: Metric or Imperial. The Toolbit Parameter Editor shows the values in the Units of the Tool Bit. CAM calculations ToolBit editor uses it for native-unit display; CAM calculations still use metric units internally.

Changing the unit schema may cause small rounding differences.

When FreeCAD saves a Tool Bit, each quantity is text in the Units of the Tool Bit with a fixed number of decimals. This fixed number of decimals is the Tool Bit precision:

  • Metric: 3 decimals. A value that is small enough for FreeCAD to show in µm has 4 decimals.

  • Imperial: 4 decimals.

The unit schema and the Units Decimals preference do not change the saved values. The unit schema applies only when the Tool Bit has no Units value. The Camotics export does not use the Tool Bit precision; see Tool Library.

Each shipped Tool Bit file has a Units entry in parameter: 375-16_Tap.fctb has Imperial and the other shipped files have Metric. The Tool Bit precision applies to the values that FreeCAD saves. Some shipped Tool Bit files have a different number of decimals.

{
  "version": 2,
  "id": "5mm_Endmill",
  "name": "5mm Endmill",
  "shape": "endmill.fcstd",
  "shape-type": "Endmill",
  "parameter": {
    "Chipload": "0.0000 mm",
    "CuttingEdgeHeight": "30.0000 mm",
    "Diameter": "5.0000 mm",
    "Flutes": 2,
    "Length": "50.0000 mm",
    "Material": "HSS",
    "ShankDiameter": "3.0000 mm",
    "SpindleDirection": "Forward",
    "Units": "Metric"
  },
  "attribute": {},
  "presets": [
    {
      "name": "Aluminium profile",
      "material_hint": {"uuid": "…", "name": "Aluminium 6061"},
      "op_type_hint": "profile",
      "surface_speed": 300.0,
      "chipload": 0.05,
      "vert_feed_ratio": 0.33,
      "notes": null
    }
  ]
}

The keys are:

  • version: always 2.

  • id: the Tool Bit ID (optional; defaults to the file name).

  • name: the label shown in the UI.

  • shape: Tool Shape ID plus .fcstd.

  • shape-type: the shape class or subtype (for example Drill or jobber).

  • parameter: shape parameters and attributes as quantity strings.

  • attribute: reserved, empty.

  • presets introduced in 26.3: optional list of Feeds & Speeds presets (surface_speed in m/min, chipload in mm per tooth).

Unknown top-level keys are preserved when the file is re-saved.

Tool Bits in a document

In a Job the Tool Bit object is shown as a child of its Tool Controller and is hidden by default. Several Tool Controllers may reference the same Tool Bit object.

A double-click on a Tool Bit in the tree view of a document opens the Toolbit Parameter Editor as a task panel. OK saves the changes to the Tool Bit in the document. Cancel discards all edits made in the task panel.

The figure shows the task panel for the Tool Bit of a new Job.

The Transform entry of the tree-view context menu of a Tool Bit starts the standard transform manipulator of FreeCAD. The Transform entry does not open the Toolbit Parameter Editor.

A Tool Bit placed in a document can be written back to a file from its tree-view context menu: Save Tool (only if the object came from a file) and Save Tool As… open a save dialog offering the FreeCAD Tool (.fctb) and YAML formats. The commands CAM_ToolBitCreate (New Toolbit) and CAM_ToolBitLoad (Load Tool) exist but are not placed in any menu.

Update from library

introduced in 26.3: when a document is opened, embedded Tool Bits are compared with the library Tool Bit that has the same ToolBitID. If presets or Shape-group values differ, the Tool Updates Available dialog lists the differences (expand a row to see old and new values) and replaces checked Tool Bits with the library version. The same check is available from the Job’s context menu entry Update Tools from Library. The automatic check can be turned off in Edit  Preferences  CAM  Assets (Check for tool updates from the library when opening a document).

introduced in 26.3: an embedded Tool Bit is a copy of a library Tool Bit and keeps the ToolBitID of the library Tool Bit. A change of the library Tool Bit does not change the embedded Tool Bit. An update from the library replaces the embedded Tool Bit with the current library Tool Bit.

FreeCAD examines the embedded Tool Bits in two cases:

  • A document opens. FreeCAD examines all Jobs of the document one time for each load, after the restore and the recompute are complete. The Tool Updates Available dialog shows only when a minimum of one Job has a changed Tool Bit. The checkbox Check for tool updates from the library when opening a document in the Preferences sets this check on or off.

  • You select Update Tools from Library in the context menu of a Job. FreeCAD examines only that Job, also when the preference is off. When the Job has no changed Tool Bit, a message box shows the text "This job has no tool updates available."

FreeCAD compares an embedded Tool Bit only with the library Tool Bit that has the same ToolBitID. The comparison does not use the label or other values to find the library Tool Bit. An embedded Tool Bit that has no ToolBitID, or a ToolBitID that is not in the library, is not in the dialog.

An embedded Tool Bit is in the dialog when its Presets are different, or when a property of the Shape group is different, or both. The comparison ignores a Shape property that only one of the two Tool Bits has. When the ShapeType of the two Tool Bits is different, FreeCAD does not compare the Shape properties.

The Tool Updates Available dialog has one row for each changed Tool Bit. The rows are in the sequence of Job label, then Tool Number. The columns of the table are:

  • A checkbox without a column title. Each row is checked by default. The checkbox in the table header checks or clears all rows.

  • Job: the label of the Job.

  • Tool #: Tool Number of the Tool Controller.

  • Tool: the label of the embedded Tool Bit.

  • Changes: Presets, Geometry or Presets, Geometry.

A row with Geometry in the Changes column expands. The expanded row shows one line for each changed property, with the property label, the old value and the new value. The expanded row also shows a line Presets when the Presets are different. A row with only Presets does not expand. The old values and the new values are shown in the Units of the library Tool Bit, not of the embedded Tool Bit.

The figure shows a row with Presets and an expanded row with Presets, Geometry.

Update replaces each checked Tool Bit and is disabled when no row is checked. Cancel is the default button and changes nothing.

An update always replaces the full Tool Bit. FreeCAD adds a new copy of the library Tool Bit to the document. FreeCAD sets the Tool property of the Tool Controller to the new object. FreeCAD removes the old Tool Bit object from the document.

An update of only the Presets or of only the Shape values is not possible, and FreeCAD does not merge the values of the two Tool Bits. The update changes no other property of the Tool Controller; see Tool Controller.

The new Tool Bit objects are hidden. FreeCAD recomputes the document one time when a minimum of one Tool Bit was replaced. FreeCAD does not replace a checked Tool Bit whose library Tool Bit no longer exists.

Clear the checkbox of a Tool Bit whose local edits you must keep. An update replaces the Presets, the Shape values, the Units and all other values of the embedded Tool Bit with the values of the library Tool Bit.

Edits of an embedded Tool Bit are stored in the document only and are not written to the library; see Feeds and Speeds.

Scripting

from Path.Tool.toolbit import ToolBit

tb = ToolBit.from_shape_id("endmill.fcstd", label="6mm Endmill")
tb.set_property("Diameter", "6 mm")
obj = tb.attach_to_doc(App.ActiveDocument)

# load from file
tb2 = ToolBit.from_file("/path/to/5mm_Endmill.fctb")

# library store access
from Path.Tool.camassets import cam_assets
tb3 = cam_assets.get("toolbit://5mm_Endmill")

The legacy module PathScripts.PathToolBit is no longer available.
