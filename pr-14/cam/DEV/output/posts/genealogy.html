Post-Processor Genealogy

Generated from src/Mod/CAM/Path/Post in the FreeCAD source tree. To change this page, change the source.

A machine-based Post-Processor is a Python class that inherits from PostProcessor in Path/Post/Processor.py, directly or through a different Post-Processor. A class gets the behaviour of its parent and replaces the parts that its control needs. Writing a Machine-Based Post-Processor describes how to write one.
