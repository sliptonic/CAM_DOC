== Overview

A xref:reference/glossary.adoc#tool-bit[Tool Bit] holds the geometry, the dimensions and the attributes of the item that cuts the xref:reference/glossary.adoc#stock[Stock].
A xref:reference/glossary.adoc#job[Job] uses a Tool Bit through a xref:reference/glossary.adoc#tool-controller[Tool Controller].
An xref:reference/glossary.adoc#operation[Operation] reads the Tool Bit of its Tool Controller to calculate a xref:reference/glossary.adoc#toolpath[Toolpath].

The CAM workbench stores each Tool Bit as a JSON file with the extension `.fctb`.
A macro or a Python script can read and write this file.
One Tool Bit can be a member of more than one xref:reference/glossary.adoc#tool-library[Tool Library].
xref:tools/index.adoc[Tools] gives the relation between Tool Bit, Tool Library and Tool Controller.

The Tool Bit file names its xref:reference/glossary.adoc#tool-shape[Tool Shape] by the ID of the Tool Shape, for example `endmill.fcstd`.
The Tool Bit file also stores the values of the shape parameters and the attributes.
The CAM workbench finds the Tool Shape in the `Tools/Shape` folder of the asset directory or in the shapes that FreeCAD supplies.
xref:tools/tool-shape.adoc[Tool Shape] lists the shapes and their parameters.

When you add a Tool Bit to a Job, the CAM workbench copies the body of the Tool Shape into the document.
The copied body is hidden, and the *Bit Body* property of the Tool Bit links to it.
The Tool Bit object receives the solid of this body.
When you change a property in the _Shape_ group, the next recompute updates the solid.

The solid has the correct shape and dimensions of the Tool Bit.
An algorithm can use the solid to make a point cloud or a mesh.

== Tool Bit editor

The _Toolbit Parameter Editor_ dialog shows and changes the values of one Tool Bit.
The dialog opens from these locations:

* The _Toolbit Library Manager_ opens the dialog when you add a Tool Bit. See xref:tools/library-manager.adoc[Toolbit Library Manager].
* A double-click on a Tool Bit in the _Toolbit Library Manager_ or in the _Toolbit Selector_ opens the dialog.
* kbd:[F2] opens the dialog for the Tool Bit that is selected in one of these two lists.

The dialog has two tabs, _Toolbit_ and _Feeds & Speeds_.
The dialog definition also contains a _Notes_ tab, and the editor hides this tab.

=== Toolbit

* *Label*: the name of the Tool Bit in the interface.
* *Toolbit Type*: the subtype of the Tool Shape. You can change the value only for a Tool Shape that has subtypes. For example, the `Drill` shape has the subtypes jobber, stub, spot, center and brad point.
* *Tool Number*: the number of the Tool Bit in the Tool Library. The field is shown only when a Tool Library is selected. For a new Tool Bit, the editor gives the next free number.
* _Properties_: one field for each property of the _Shape_ group and the _Attributes_ group. The label of a shape parameter shows the abbreviation that the shape drawing uses for this parameter.
* Shape drawing: the drawing of the Tool Shape with its dimensions. See xref:tools/tool-shape.adoc[Tool Shape].

The figure shows the _Toolbit_ tab for a Tool Bit with the `Endmill` shape.

image::tools/toolbit/editor-toolbit-tab.png["Toolbit Parameter Editor, Toolbit tab, for a 5 mm Endmill, with the properties and the shape drawing",400]

[.since]#introduced in 26.3#: The _Properties_ list does not show a derived property.
The CAM workbench calculates a derived property from the other shape parameters.
See <<properties,Properties>> for the derived property of the `Chamfer` shape.

[.since]#introduced in 26.3#: The shape drawing and the _Properties_ list are connected:

* Move the pointer on a dimension in the shape drawing. The editor highlights the dimension and the field of its property.
* Move the pointer on the row of a property. The editor highlights the dimension of this property in the shape drawing.
* Click a dimension in the shape drawing. The field of its property gets the keyboard focus, and the editor selects the content of the field.

The figure shows the _Toolbit_ tab with the pointer on the `D` dimension.

image::tools/toolbit/editor-dimension-highlight.png["Toolbit tab with the D dimension of the shape drawing and the Diameter field highlighted",400]

While the editor is open, the unit schema of FreeCAD is the schema of the *Units* value of the Tool Bit.
Thus you enter each parameter in the unit system of the Tool Bit.
When the editor closes, the editor sets the unit schema that was active before.

[.since]#introduced in 26.3#: The fields show a `Metric` value with 3 decimals and an `Imperial` value with 4 decimals.
The decimals preference of FreeCAD does not change the precision of these fields.

=== Feeds & Speeds

[.since]#introduced in 26.3#: The _Feeds & Speeds_ tab shows a table of the xref:reference/glossary.adoc#preset[Presets] that the Tool Bit stores.
The tab has the buttons btn:[Add preset], btn:[Edit], btn:[Copy] and btn:[Delete].
A Preset has a name, and a Preset can have a note.

== Properties

.Base
* *Shape ID* (`String`, read-only): the ID of the Tool Shape, a `.fcstd` file name.
* *Shape Type* (`Enumeration`, read-only): the shape class. Values: `Endmill`, `Ballend`, `Bullnose`, `Chamfer`, `Drill`, `VBit`, `Dovetail`, `Reamer`, `SlittingSaw`, `Tap`, `ThreadMill`, `Probe`, `TaperedBallNose`, `Radius`, `Custom`.
* *Tool Bit ID* (`String`, read-only): the unique ID of the Tool Bit. The ID is the file name of the Tool Bit in the library.
* *Bit Body* (`Link`, hidden): the body that the shape parameters control.

.Shape
* One property for each parameter of the Tool Shape, for example *Diameter*, *Length*, *Cutting Edge Height*, *Shank Diameter* and *Flutes*. See xref:tools/tool-shape.adoc[Tool Shape] for the parameters of each shape.
* [.since]#introduced in 26.3# *Diameter* of the `Chamfer` shape (read-only): a derived property. The value is `TipDiameter + 2 * CuttingEdgeHeight * tan(CuttingEdgeAngle / 2)`.

.Attributes
* [.since]#introduced in 26.3# *Units* (`Enumeration`): the unit system of the Tool Bit. The Tool Bit editor and the Tool Bit file use this unit system. Values: `Metric`, `Imperial`.
* *Spindle Direction* (`Enumeration`): the default direction of the spindle. The Tool Controller receives this value when you add the Tool Bit to a Job. A Tool Bit with the `Probe` shape does not turn. Values: `Forward`, `Reverse`, `None`.
* *Material* (`Enumeration`): the material of the Tool Bit. The Feeds and Speeds helper uses the value to select the applicable surface speed of the Stock material. Values: `HSS`, `Carbide`.
* *Chipload* (`Length`): the default chipload for each tooth. Only a Tool Bit that cuts has this property. The Feeds and Speeds helper uses the value as a fallback of low confidence.

.Feeds & Speeds
* [.since]#introduced in 26.3# *Presets* (`String`): a JSON list of the Presets. The Tool Bit has this property only after you save a Preset.

== File format

A Tool Bit file is a JSON file with the extension `.fctb`.

[source,json]
----
{
  "version": 2,
  "id": "5mm_Endmill",
  "name": "5mm Endmill",
  "shape": "endmill.fcstd",
  "shape-type": "Endmill",
  "parameter": {
    "Chipload": "0.0500 mm",
    "CuttingEdgeHeight": "30.000 mm",
    "Diameter": "5.000 mm",
    "Flutes": 2,
    "Length": "50.000 mm",
    "Material": "HSS",
    "ShankDiameter": "3.000 mm",
    "SpindleDirection": "Forward",
    "Units": "Metric"
  },
  "attribute": {},
  "presets": [
    {
      "name": "Aluminium profile",
      "material_hint": {"uuid": null, "name": "Aluminium 6061"},
      "op_type_hint": "profile",
      "surface_speed": 300.0,
      "chipload": 0.05,
      "vert_feed_ratio": 0.33,
      "notes": null
    }
  ]
}
----

The keys are:

* `version`: always 2.
* `id`: the Tool Bit ID. The key is optional. The default is the file name.
* `name`: the label that the interface shows.
* `shape`: the ID of the Tool Shape with the extension `.fcstd`.
* `shape-type`: the shape class or the subtype, for example `Drill` or `jobber`.
* `parameter`: the shape parameters and the attributes. A quantity is a string with a value and a unit.
* `attribute`: reserved and empty.
* [.since]#introduced in 26.3# `presets`: an optional list of Presets. `surface_speed` is in m/min. `chipload` is in mm for each tooth. `notes` is optional free text.

When the CAM workbench saves the file again, it keeps the top-level keys that it does not know.

[.since]#introduced in 26.3#: The `Units` parameter has the value `Metric` or `Imperial`.
The Tool Bit files that FreeCAD supplies contain this parameter.
The CAM workbench calculates in metric units internally.
A change of the *Units* value can cause small differences because of the round-off.

[.since]#introduced in 26.3#: The CAM workbench writes each quantity in the unit system of the *Units* value of the Tool Bit.
A `Metric` quantity has 3 decimals, and an `Imperial` quantity has 4 decimals.
A `Metric` length less than 0.1 mm has 4 decimals.
The active unit schema and the decimals preference of FreeCAD do not change the values in the file.

== Tool Bits in a document

In a Job, the https://wiki.freecad.org/Tree_view[tree view] shows the Tool Bit object as a child of its xref:tools/tool-controller.adoc[Tool Controller].
The Tool Bit object is hidden by default.
A Tool Bit object in a document belongs to one Tool Controller.

[.since]#introduced in 26.3#: A double-click on the Tool Bit object in the tree view opens the https://wiki.freecad.org/Task_panel[task panel] of the Tool Bit.
The task panel shows the properties form and the shape drawing of the Tool Bit editor.

image::tools/toolbit/task-panel.png["Task panel of a Tool Bit object, with the properties form and the shape drawing",600]

btn:[OK] applies the changes to the Tool Bit.
btn:[Cancel] discards all changes that you made in the task panel.

[.since]#introduced in 26.3#: The menu:Transform[] entry of the context menu starts the https://wiki.freecad.org/Std_TransformManip[Std TransformManip] command for the Tool Bit object.
This command moves and turns the solid of the Tool Bit in the 3D view.

The context menu of the Tool Bit object in the tree view writes the Tool Bit to a file:

* menu:Save Tool[]: saves the Tool Bit to its file. The entry is available only if the Tool Bit object came from a file.
* menu:Save Tool As…[]: opens a save dialog. The dialog gives the formats FreeCAD Tool (`.fctb`) and YAML.

The command `CAM_ToolBitCreate` has the label _New Toolbit_, and the command `CAM_ToolBitLoad` has the label _Load Tool_.
No menu contains these two commands.

== Update from the Tool Library

[.since]#introduced in 26.3#: The CAM workbench compares each Tool Bit of a Job with the Tool Bit in the library that has the same *Tool Bit ID*.
The comparison includes the Presets and the properties of the _Shape_ group.
The CAM workbench does not compare or change a Tool Bit that has no match in the library.
When the *Shape Type* of the two Tool Bits is different, the CAM workbench does not compare the _Shape_ group.

The comparison starts in two conditions:

* You open a document. The comparison occurs one time for each load of the document. The checkbox *Check for tool updates from the library when opening a document* in menu:Edit[Preferences > CAM > Assets] sets or stops this comparison.
* You select menu:Update Tools from Library[] in the context menu of the Job. When no Tool Bit is different, a message tells you that no updates are available.

When a Tool Bit is different, the _Tool Updates Available_ dialog opens.
The table of the dialog has one row for each Tool Bit that is different, with these columns:

* Checkbox: selects the Tool Bit for the update. Default: set. The checkbox in the table header sets or clears all rows.
* *Job*: the label of the Job.
* *Tool #*: the number of the Tool Controller.
* *Tool*: the label of the Tool Bit.
* *Changes*: the type of the difference, `Presets`, `Geometry` or the two. Expand a row with `Geometry` to see each changed property with its old value and its new value.

The *Changes* column shows the two values in the unit system of the library Tool Bit.
The figure shows the dialog with one `Presets` row and one expanded `Geometry` row.

image::tools/toolbit/tool-updates-available.png["Tool Updates Available dialog with a Presets row and an expanded Geometry row with old and new values",400]

The dialog has two buttons:

* btn:[Update]: replaces each selected Tool Bit with a new copy of the library Tool Bit, then recomputes the document. The button is not available when no row is selected.
* btn:[Cancel]: closes the dialog and changes nothing. btn:[Cancel] is the default button.

The update replaces the whole Tool Bit: the Presets, the shape parameters, the attributes and the *Units* value.
The CAM workbench links the Tool Controller to the new Tool Bit object and removes the old Tool Bit object from the document.
The new Tool Bit object is hidden.

CAUTION: Examine the *Changes* column before you press btn:[Update]. The update replaces the whole Tool Bit, and values that you changed only in the document are lost.

== Scripting

[source,python]
----
from Path.Tool.toolbit import ToolBit

tb = ToolBit.from_shape_id("endmill.fcstd", label="6mm Endmill")
tb.set_property("Diameter", "6 mm")
obj = tb.attach_to_doc(App.ActiveDocument)

# load from file
tb2 = ToolBit.from_file("/path/to/5mm_Endmill.fctb")

# library store access
from Path.Tool.camassets import cam_assets
tb3 = cam_assets.get("toolbit://5mm_Endmill")
----

The module `PathScripts.PathToolBit` does not exist.
