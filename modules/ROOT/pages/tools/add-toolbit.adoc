== Description

The *Add Toolbit…* command opens the _Toolbit Selector_ dialog.
The dialog shows the xref:reference/glossary.adoc#tool-bit[Tool Bits] of a xref:reference/glossary.adoc#tool-library[Tool Library].
The dialog creates one xref:reference/glossary.adoc#tool-controller[Tool Controller] (TC) in a xref:reference/glossary.adoc#job[Job] for each Tool Bit that you select.
The command requires a document that contains a Job.

xref:tools/toolbit-library.adoc[Tool Library] describes how the dialog adds a Tool Bit to a Job.
xref:tools/toolbit-library.adoc#tool-numbers[Tool numbers] describes how the CAM workbench sets the number of the new TC.

== Usage

. Open the _Toolbit Selector_ dialog with one of these controls:
* Press the image:CAM_ToolTable.svg[Add Toolbit…,16] btn:[Add Toolbit…] button in the _Tool Commands_ toolbar.
* Select menu:CAM[Add Toolbit…].
* Press kbd:[P] and then kbd:[T].
. Select a Tool Library in the library list, or select _All Tools_.
. Select one or more Tool Bits in the list.
. Press btn:[Add to Job]. As an alternative, double-click one Tool Bit.
. If the document contains more than one Job, select the Job in the dialog that opens.
. If the _Tool Number_ dialog opens, enter the number for the TC and press btn:[OK].
. Press btn:[Close].

== Options

The _Toolbit Selector_ dialog has these controls above the Tool Bit list:

* Library list: selects the Tool Library that the dialog shows. The dialog opens with the Tool Library that you used last.
* [.since]#introduced in 26.3# _All Tools_: the first entry of the library list. The entry shows each Tool Bit in the asset directory.
* Type filter: shows only the Tool Bits of one shape type. Default: `All Toolbit Types`.
* Sort list: sets the sequence of the Tool Bit list. The dialog hides this control when _All Tools_ is selected.
* Search box: shows only the Tool Bits that match the text.

The figure shows the dialog with _All Tools_ selected.

image::tools/add-toolbit/toolbit-selector-all-tools.png["Toolbit Selector dialog with All Tools selected, without the sort list and without numbers in the rows",400]

Each row of the Tool Bit list shows these items:

* The number of the Tool Bit in the selected Tool Library. A Tool Bit in the _All Tools_ view has no number.
* The label of the Tool Bit.
* The summary of the Tool Bit, on one line.
* The shape icon of the Tool Bit. The icon shows the Tool Bit artwork without the dimensions. See xref:tools/tool-shape.adoc[Tool Shape].

The figure shows the dialog with the `Default` Tool Library selected.

image::tools/add-toolbit/toolbit-selector.png["Toolbit Selector dialog with the Default Tool Library selected, where each row shows the number, the label, the summary and the shape icon of a Tool Bit",400]

[.since]#introduced in 26.3#: The summary shows each length in the unit system of the Tool Bit.
A `Metric` length has 3 decimals, and an `Imperial` length has 4 decimals.
An example of a summary is _5.000 mm 4-flute endmill, 30.000 mm cutting edge_.

The dialog has these buttons below the Tool Bit list:

* btn:[Open Library Editor]: opens the _Library Manager_ dialog. See xref:tools/library-manager.adoc[Toolbit Library Manager].
* btn:[Add to Job]: creates one TC for each selected Tool Bit. The button is available only when a Tool Bit is selected and the document contains a Job.
* btn:[Close]: closes the dialog.

== Notes and limitations

* The _Toolbit Selector_ is a dialog. The _Toolbit Selector_ is not a dock panel.
* If the document contains no Job, the message _Create a Job first_ appears.
* The new TC has the label `TC:` and the label of the Tool Bit.
* The new TC gets the *Spindle Direction* value of the Tool Bit.
* The number of the Tool Bit in the Tool Library is only the proposal for the *Tool Number* property of the new TC.
* Two TCs of a Job can have the same *Tool Number* only when they use the same Tool Bit.

[.since]#introduced in 26.3#: The _Tool Number_ dialog asks for a number when the Tool Bit has no library number.
The _Tool Number_ dialog also asks for a number when a TC of a different Tool Bit has the library number.
If you cancel the _Tool Number_ dialog, the CAM workbench does not add this Tool Bit to the Job.
See xref:tools/toolbit-library.adoc#tool-numbers[Tool numbers] for the full rules.
The figure shows the _Tool Number_ dialog when a TC of a different Tool Bit has the library number.

image::tools/add-toolbit/tool-number-dialog.png["Tool Number dialog with the text Tool number 1 is already used by TC: 5mm Endmill, and the next free number 2 as the value",400]

[.since]#introduced in 26.3#: These controls open the same _Toolbit Selector_ dialog:

* btn:[Add] on the _Tools_ tab of the Job editor.
* The last entry of the *Tool controller* list in the task panel of an xref:reference/glossary.adoc#operation[Operation].
* The command `CAM_ToolController`. No menu and no toolbar contains this command.
