CAM Tools

Description

This page describes the tool management system of the CAM Workbench. Tool Shapes, Tool Bits and Tool Libraries are stored as files (assets) in a user-configurable asset directory and are managed through the Library Manager. introduced in 1.1: the tool management system was rewritten around a CAM asset store; the Toolbit Parameter Editor, Toolbit Selector and Library Manager described below replaced the earlier dialogs.

There are several concepts that the user needs to understand:

  • Tool Shapes: are templates for creating Tool Bits. Tool Shapes are FreeCAD documents (.fcstd) containing a PartDesign Body driven by a PropertyBag named Attributes. The label of the Body selects the shape type (for example Endmill or Drill), which defines the list of parameters a Tool Bit of that shape carries. An unknown label is treated as the Custom shape. The Tool Shape is an abstract template from which tool instances (called Tool Bits) are created; for example, all endmills share the same Tool Shape file.

  • Tool Bits: are instances of a Tool Shape. A Tool Bit is a .fctb file (JSON) holding a reference to a Tool Shape, the values of the shape parameters and additional attributes (Units, Spindle Direction, Material, Chipload, Feeds & Speeds presets). A Tool Bit is identified by its file name (ID) and may be listed in any number of Tool Libraries. A Tool Bit is used in a Job through a Tool Controller.

  • Tool Libraries: contain an arbitrary collection of Tool Bits. The specific Tool Bits in a library are entirely up to the user. Possible use cases for libraries:

    • A hobbyist user may have only one library for all of the tools they own.

    • A library may contain all the Tool Bits used for a specific material like aluminum or wood.

    • A library may hold Tool Bits from a specific supplier.

    • A library may correspond to an automatic tool changer layout.

A Tool Controller pairs a Tool Bit with a tool number, spindle speed and direction, horizontal and vertical feed rates, rapid rates and (by default derived from the horizontal feed) ramp, lead-in and lead-out feed rates.

Dialogs

The user interacts with the tool management system through two dialogs reached from the CAM menu:

  • Add Toolbit… (CAM  Add Toolbit…, window title Toolbit Selector): pick Tool Bits from a library and add them to a Job as Tool Controllers.

  • Toolbit Library Manager (CAM  Toolbit Library Manager, window title Library Manager): create, edit, import and export Tool Bits and Tool Libraries.

Organization

When FreeCAD is installed an example hierarchy of Tool Libraries and Tool Bits is created in the installation directory at:

  • On Linux it is usually /usr/lib64/FreeCAD/Mod/CAM/Tools

  • On Windows it is usually C:\Program Files\FreeCAD\Mod\CAM\Tools

  • On macOS it is usually /Applications/FreeCAD.app/Contents/Resources/Mod/CAM/Tools

Tools

  + Library
  + Shape

introduced in 1.1: user Tool Bits, Tool Libraries and Tool Shapes are stored in the CAM asset directory, by default CamAssets inside the FreeCAD user application data directory. The location is set in Edit  Preferences  CAM  Assets (see CAM Preferences). The directory contains Tools/Bit, Tools/Library and Tools/Shape as well as Machines (machine templates) and Templates (Job Templates). On first use the shipped Tool Bits and the Default library are copied into this directory; the shipped Tool Shapes are resolved from the installation as a fallback.

Changes made in the Library Manager (new libraries, renamed libraries, new or edited Tool Bits, tool numbers) are written to the asset directory immediately; there is no separate save step.

Migration from earlier versions

introduced in 1.1: when the CAM Workbench is activated and a custom tool directory from an earlier version is found, a CAM Asset Migration dialog offers to copy the Tool Bits, Tool Libraries and Tool Shapes into the asset directory. Tool Bits embedded in older documents are upgraded when the document is opened (legacy property names such as ShapeName and BitShape are converted).

The legacy (pre-0.19) tool table is not supported; templates that reference legacy tools are rejected with the message that legacy tools are no longer supported. obsolete since 1.1

Getting started

Create a Tool Bit

  1. Select CAM  Toolbit Library Manager.

  2. Select the library that should receive the new Tool Bit, or All Toolbits to create a Tool Bit that is not yet in any library.

  3. Press the Adds a toolbit button. The Toolbit Shape Selection dialog lists the shipped and user Tool Shapes.

  4. Select a shape. The Toolbit Parameter Editor opens; enter a Label, the Tool Number and the shape parameters and attributes, then press OK. The Tool Bit is saved to the asset directory and added to the selected library immediately.

Add a Tool Controller to a Job

  1. Select CAM  Add Toolbit… (or press P then T).

  2. Select a library in the drop-down, select one or more Tool Bits and press Add to Job, or double-click a Tool Bit.

  3. If the document contains several Jobs you are asked which Job to use.

Feeds and speeds

introduced in 26.3: a Tool Bit can store Feeds & Speeds presets (surface speed and chipload per material and operation type). The Feeds and Speeds helper of the Tool Controller editor uses these presets, the Stock material and the Machine spindle limits to suggest spindle speed and feed rates. See CAM FeedsSpeeds.

Tool update from library

introduced in 26.3: Tool Bits embedded in a Job keep the ID of the library Tool Bit they were created from. When a document is opened, CAM compares the embedded Tool Bits with the library and offers to replace changed ones (Tool Updates Available dialog). The check can be run manually from the Job’s context menu (Update Tools from Library) and disabled in Edit  Preferences  CAM  Assets.

Tool Bit units

introduced in 26.3: every Tool Bit has a Units attribute (Metric or Imperial). The Toolbit Parameter Editor shows the parameters in that unit system; internally all values remain millimetres.

Import and export

Tool Bits can be imported from and exported to .fctb (FreeCAD Tool) and YAML (.yaml, .yml) files; Tool Libraries can be imported from and exported to .fctl (FreeCAD Tool Library) and Camotics (.json) files and exported as a LinuxCNC tool table (.tbl).

Machines

Machine templates (.fcm) are also stored in the asset directory (Machines folder) and are managed from Edit  Preferences  CAM  Assets. See CAM Machine.

Overview

The CAM workbench describes the item that cuts with four objects. A Tool Shape is a template. A Tool Bit is one item with its dimensions. A Tool Library is a numbered list of Tool Bits. A Tool Controller (TC) connects one Tool Bit to the feeds and the Spindle Speed of a Job.

The CAM workbench stores each Tool Shape, each Tool Bit and each Tool Library as a file in the asset directory. A TC is an object in the document of the Job. This page gives the relation between these objects and links to each page of the section.

Relation between the objects

  • Tool Shape: a FreeCAD document (.fcstd) that gives the physical shape and the parameter names of a Tool Bit. Many Tool Bits can use one Tool Shape. For example, all Tool Bits of the Endmill type use the same Tool Shape file. See Tool Shape.

  • Tool Bit: a JSON file (.fctb) that names one Tool Shape and holds the parameter values and the attributes. The file name is the ID of the Tool Bit. See Tool Bit.

  • Tool Library: a JSON file (.fctl) that gives a number to each Tool Bit ID. A Tool Library is independent of a Job. One Tool Bit can be a member of more than one Tool Library. See Tool Library.

  • Tool Controller: an object in the Tools group of a Job. A TC connects one Tool Bit to a Tool Number, a Spindle Speed, a spindle direction, the feeds and the rates of the rapid moves. See Tool Controller.

An Operation refers to a TC. An Operation does not refer to a Tool Bit directly. The Operation reads the Tool Bit of its TC to calculate the Toolpath.

When you add a Tool Bit to a Job, the CAM workbench puts a copy of the Tool Bit into the document. The TC owns this Tool Bit object. The Tool Bit object keeps the ID of the library Tool Bit. A change of the library Tool Bit does not change the Tool Bit object in the Job. See Update from the Tool Library.

The figure shows the tree view of a Job with one TC in the Tools group and the Tool Bit object below the TC.

More than one TC of a Job can use the same Tool Bit with different feeds and speeds. The number of a Tool Bit in a Tool Library is only the proposal for the Tool Number of a new TC. See Tool numbers.

Commands

Two commands of the CAM menu give access to each Tool Bit and each Tool Library:

  • Add Toolbit…, CAM  Add Toolbit…: opens the Toolbit Selector dialog. The dialog adds the selected Tool Bits to a Job as TCs.

  • Toolbit Library Manager, CAM  Toolbit Library Manager: opens the Library Manager dialog. The dialog creates, changes, imports and exports Tool Bits and Tool Libraries.

Work sequence

The usual sequence from a new Tool Bit to an Operation is:

  1. Select CAM  Toolbit Library Manager.

  2. Select the Tool Library for the new Tool Bit, or select All Toolbits.

  3. Press Adds a toolbit. The Toolbit Shape Selection dialog lists the supplied Tool Shapes and your own Tool Shapes.

  4. Select a Tool Shape. The Toolbit Parameter Editor dialog opens.

  5. Enter the values of the Tool Bit and press OK. See Tool Bit.

  6. Close the Library Manager dialog.

  7. Select CAM  Add Toolbit….

  8. Select the Tool Bit and press Add to Job. The CAM workbench creates a TC in the Job.

  9. Select the TC in the task panel of an Operation.

Toolbit Library Manager and Add Toolbit… describe the controls of the two dialogs.

Asset directory

introduced in 1.1: The CAM workbench stores your Tool Bits, Tool Libraries and Tool Shapes in the CAM asset directory. The default asset directory is CamAssets in the application data directory of FreeCAD. Edit  Preferences  CAM  Assets sets the location of the asset directory. See CAM Preferences.

The asset directory contains these folders:

  • Tools/Bit: the Tool Bit files.

  • Tools/Library: the Tool Library files.

  • Tools/Shape: your own Tool Shapes.

  • Machines: the Machine Templates (.fcm). Edit  Preferences  CAM  Assets adds and changes the Machine Templates. See Machine.

  • Templates: the Job Templates.

FreeCAD supplies a set of Tool Bits, Tool Libraries and Tool Shapes in the folders Bit, Library and Shape of the installation directory. The location of these folders is usually:

  • Linux: /usr/lib64/FreeCAD/Mod/CAM/Tools

  • Windows: C:\Program Files\FreeCAD\Mod\CAM\Tools

  • macOS: /Applications/FreeCAD.app/Contents/Resources/Mod/CAM/Tools

The CAM workbench copies the supplied Tool Bits and the Default Tool Library into the asset directory. See Tool Library. When the asset directory does not contain a Tool Shape, the CAM workbench uses the supplied Tool Shape in the installation directory.

The Library Manager dialog writes each change to the asset directory immediately. The Library Manager dialog has no separate save step.

introduced in 1.1: When you activate the CAM workbench, the CAM workbench looks for a custom tool directory of an earlier version. If the CAM workbench finds this directory, the CAM Asset Migration dialog opens. The CAM Asset Migration dialog offers to copy each Tool Bit, each Tool Library and each Tool Shape into the asset directory.

When you open a document, the CAM workbench converts the Tool Bit property names ShapeName and BitShape to the current names. The CAM workbench does not load a Job Template that uses the tool table of the versions before 0.19.

Update from the Tool Library

introduced in 26.3: The CAM workbench compares the Tool Bits of a Job with the Tool Bits in the library. The CAM workbench finds the library Tool Bit by the ID that the Tool Bit object of the Job keeps. The comparison starts in two conditions:

  • You open a document. The checkbox Check for tool updates from the library when opening a document in Edit  Preferences  CAM  Assets sets or stops this comparison.

  • You select Update Tools from Library in the context menu of the Job.

When a Tool Bit of a Job is different from the library Tool Bit, the Tool Updates Available dialog opens. Update replaces each selected Tool Bit of the Job with the current library Tool Bit and recomputes the document. Cancel changes nothing.

Tool Bit describes the comparison and the Tool Updates Available dialog. Tool Controller describes the effect of the update on the TC.

Feeds and Speeds

introduced in 26.3: A Tool Bit can store Presets. A Preset holds a surface speed and a chipload for one material and one type of cut. The Feeds and Speeds helper of the Tool Controller editor suggests the Spindle Speed and the feeds of a TC. The helper uses the Presets, the material of the Stock and the spindle limits of the Machine. See Feeds and Speeds.
